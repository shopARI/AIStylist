01 / Architecture

System Flow

From User Input to Personalized Recommendations

USER INPUT
"I need something for a casual Friday at work, nothing too formal"
↓
1. INTENT DETECTION
Classify intent (search, browse, clarification, feedback) + extract entities
↓
2. SYNTHESIS LLM
Combine user profile + query → search strategy, budget, style descriptors
↓
3. PERSONALIZATION (Pillar 1)
Compute user embeddings, trajectory, context-aware position
↓
4. SEMANTIC SEARCH + VISUAL SEARCH
Query Qdrant (OpenAI 1536d + SigLIP 1024d embeddings)
↓
5. JUDGE (Evaluator + MMR + Outliers)
Score, diversify, inject exploration products
↓
6. NARRATIVE LLM
Generate natural language response with product explanations
↓
ARI OUTPUT
"Here are some pieces that blend professional polish with weekend ease..."
+ Scored products + Match explanations + Provenance trace

04 / Explanatory Mode

Explanatory Power

Users can ask "Why did you recommend this?"

What It Does

Traces every recommendation back to its source:

  • Which profile data influenced the pick
  • Score breakdown by dimension
  • What was excluded and why
  • Navigation decisions made
EXPLAIN ON EXPLAIN OFF

Example Output

User: "Why this blazer?" ARI: "I suggested this blazer because: • It matches the minimalist style you mentioned loving (0.85 style score) • At $180, it's in your sweet spot (0.92 budget score) • Navy works with your stated color preferences (0.78 color score) Your recent purchases from Theory and COS show you gravitate toward clean lines - this fits that pattern."
05 / Visual Features

Semantic + Visual Search

Dual embedding system for comprehensive understanding

Semantic Search

OpenAI text-embedding-ada-002 (1536d)

  • Understands product descriptions
  • Captures style concepts
  • Matches user intent to products
ALWAYS ON

Visual Search

FashionSigLIP (1024d)

  • Understands product images
  • Captures texture, pattern, silhouette
  • Color harmony detection
VISUAL ON VISUAL OFF

Fusion Strategies

weighted_average

60% semantic + 40% visual

max

Best score wins

cascade

Visual re-ranks semantic

06 / Demo Commands

Running the Demo

Basic Demo (Semantic Only)

python demo_cli.py --user test_user_1

With Visual Search

python demo_cli.py --user test_user_1 --visual

Full Visual Pipeline

python demo_cli.py --user test_user_1 --all-visual

Custom Visual Weight

python demo_cli.py --user test_user_1 --visual --visual-weight 0.5

Debug Mode

python demo_cli.py --user test_user_1 --debug

In-Session Commands

/flags - Show current feature flags

/debug - Toggle debug output

"Why did you recommend this?" - Trigger explanatory mode
