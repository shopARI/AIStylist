4. Texture Extraction Pipeline

Steps:

  1. Segment: SAM3 text prompt ("dress", "shirt") produces binary mask
  2. Extract: Apply Gabor filters, LBP, GLCM to masked region
  3. Combine: Texture vector (~256-512 dim) + FPN features + color features

Code Reference:

# Texture extraction on SAM3-masked regions
from skimage.feature import graycomatrix, graycoprops, local_binary_pattern
from skimage.filters import gabor

# Load mask from SAM3
mask = np.array(Image.open(f"masks/{product_id}_mask_0.png")) > 127

# Apply mask to isolate garment
garment_pixels = image[mask]

# Gabor texture features (orientation/frequency)
for theta in [0, np.pi/4, np.pi/2, 3*np.pi/4]:
    filt_real, _ = gabor(gray, frequency=0.2, theta=theta)
    texture_features.append(filt_real[mask].mean())

# LBP for micro-patterns
lbp = local_binary_pattern(gray, P=8, R=1)
lbp_hist, _ = np.histogram(lbp[mask], bins=10, density=True)

Code Reference:

# 3D Reconstruction with SAM 3D Objects
from sam3d_objects.pipeline.inference_pipeline_pointmap import InferencePipelinePointMap

# Load image + SAM3 mask
image = load_image(f"/sam3_product_outputs/images/{product_id}.png")
mask = load_mask(f"/sam3_product_outputs/masks/{product_id}_mask_0.png")

# Merge to RGBA (image + mask as alpha)
rgba_image = np.concatenate([image[:,:,:3], mask[:,:,None]*255], axis=-1)

# Run 3D reconstruction
output = pipeline.run(
    rgba_image,
    with_mesh_postprocess=True,
    use_vertex_color=True,
)

# Save outputs
output["gs"].save_ply(f"{product_id}_3d.ply")
output["glb"].export(f"{product_id}_3d.glb")
