Node Types (9 Total)

  • Core: User (center node)
  • Profile: Demographic, Personality
  • Preferences: StylePreference, Brand, Color, Occasion
  • Social: SocialProfile, User (connections)
  • Products: Product (interactions & catalog)

Relationship Types (15 Total)

  • Preferences: PREFERS_STYLE, LOVES_BRAND, AVOIDS_BRAND, PREFERS_COLOR, DRESSES_FOR

  • Behavioral: VIEWED, PURCHASED, SAVED, SHARED, INTERACTED

Design Principles

  • Circular Layout: Organized by data type in concentric rings
  • Query-Optimized: Schema designed for "find similar users" queries
  • Weighted Relationships: Properties like strength, score, intensity on edges
  • Temporal Tracking: Timestamps on behavioral relationships
  • Hybrid Storage: Graph structure + vector embeddings for semantic search
  • Privacy-Ready: Separates PII from preferences for granular access control
